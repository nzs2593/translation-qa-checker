CHECKform for Crowdin — Privacy Policy

Last updated: 27 November 2026

CHECKform for Crowdin is a translation quality checker for visible segments in the configured Crowdin editor.

Data the extension uses

The extension reads source and translation text in visible Crowdin editor segments and the source and target locale identifiers in the editor URL. It uses this information to show potential quality findings in the same browser tab. It does not modify or save translations in Crowdin.

Storage and sharing

Quality checks run locally in the browser. The extension does not send segment text or findings to the publisher or another server. It does not use analytics or advertising.

The extension downloads shared glossary changes from checkform-glossary.nzs2593.workers.dev. This request contains no Crowdin segment text or findings. The last downloaded copy, check preferences, personal glossary edits, and time zone rules are stored locally using Chrome extension storage. Users can also import personal settings from a JSON file they choose.

Members who edit the shared glossary enter a personal access code on the CHECKform website. The code is saved in that browser's local storage only when the member chooses to save it, and is sent over HTTPS to the CHECKform Cloudflare Worker when publishing a glossary change. The Worker stores a one-way code hash, the assigned member name, glossary revisions and an audit history containing the changed term, language, previous and new translation, and optional root. It does not receive Crowdin document text. The publisher can revoke an individual code. Other team members do not receive access to the Cloudflare account or D1 console.

The shared glossary read endpoint is public, as the base glossary on the CHECKform website already is. Only publishing a change requires a personal code. Publishing sends the chosen source term, language, previous and new translation, and optional root to the Worker; it does not send source or target document contents.

Permissions

The extension requests access to the configured Crowdin host to read and annotate visible editor segments, to nzs2593.github.io for connection settings, and to checkform-glossary.nzs2593.workers.dev for shared glossary reading. The storage permission keeps user-selected settings and the glossary cache on the device.

Contact

Questions and bug reports: CHECKform issue tracker.

Политика конфиденциальности

Обновлено 27 ноября 2026 года. CHECKform читает видимые исходные и переведённые сегменты в настроенном редакторе Crowdin и показывает замечания в той же вкладке. Проверка выполняется локально. Расширение не изменяет перевод, не передаёт тексты сегментов или замечания на сервер и не использует аналитику или рекламу.

Расширение загружает общие изменения словаря с сервера CHECKform в Cloudflare и сохраняет последнюю копию в хранилище Chrome. Для публикации правки на сайте CHECKform участник вводит персональный код. Сайт сохраняет код в локальном хранилище браузера только по желанию участника и отправляет его серверу по HTTPS при публикации. Сервер хранит хеш кода, имя назначенного участника, версии словаря и историю правок. Тексты документов Crowdin туда не передаются; доступ к аккаунту Cloudflare и консоли D1 есть только у владельца. Личные настройки и правила GMT остаются в Chrome. По вопросам работы расширения используйте раздел Issues.
