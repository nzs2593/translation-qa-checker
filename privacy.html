CHECKform for Crowdin — Privacy Policy

Last updated: 17 November 2026

CHECKform for Crowdin is a translation quality checker for visible segments in the configured Crowdin editor.

Data the extension uses

The extension reads source and translation text in visible Crowdin editor segments and the source and target locale identifiers in the editor URL. It uses this information to show potential quality findings in the same browser tab. It does not modify or save translations in Crowdin.

Storage and sharing

Quality checks run locally in the browser. The extension does not send segment text or findings to the publisher or another server. It does not use analytics or advertising.

The extension downloads the published shared glossary JSON from nzs2593.github.io. This request contains no Crowdin segment text or findings. The last downloaded copy, check preferences, personal glossary edits, and time zone rules are stored locally using Chrome extension storage. Users can also import personal settings from a JSON file they choose.

On the CHECKform website, a user who chooses to propose a glossary change opens a GitHub Issue containing the selected term, language, proposed translation and optional root. Issues in the public repository are public. This action does not include source or target document contents.

Permissions

The extension requests access to the configured Crowdin host to read and annotate visible editor segments, and to nzs2593.github.io to download the shared glossary. The storage permission keeps user-selected settings and the glossary cache on the device.

Contact

Questions and bug reports: CHECKform issue tracker.

Политика конфиденциальности

Обновлено 17 ноября 2026 года. CHECKform читает видимые исходные и переведённые сегменты в настроенном редакторе Crowdin и показывает замечания в той же вкладке. Проверка выполняется локально. Расширение не изменяет перевод, не передаёт тексты сегментов или замечания на сервер и не использует аналитику или рекламу.

Расширение загружает опубликованный общий глоссарий с nzs2593.github.io и сохраняет последнюю копию в хранилище Chrome. Запрос не содержит текстов сегментов или замечаний. Личные настройки, правки словаря и правила GMT также хранятся в Chrome. Предложение по словарю, отправленное через сайт CHECKform, открывает публичный GitHub Issue с термином, языком, переводом и необязательным корнем. По вопросам работы расширения используйте раздел Issues.
