CHECKform for Crowdin — Privacy Policy

Last updated: 13 November 2026

CHECKform for Crowdin is a translation quality checker for visible segments in the marathonbetops.crowdin.com editor.

Data the extension uses

The extension reads source and translation text in visible Crowdin editor segments and the source and target locale identifiers in the editor URL. It uses this information to show potential quality findings in the same browser tab. It does not modify or save translations in Crowdin.

Storage and sharing

Quality checks run locally in the browser. The extension does not send segment text, findings, or browsing activity to the publisher or another server. It does not use analytics or advertising.

Check preferences, glossary edits, and time zone rules are stored locally using Chrome extension storage. Users can import glossary and time zone settings from a JSON file they choose. These settings are not automatically synchronized with the CHECKform website.

Permissions

The extension requests access only to marathonbetops.crowdin.com to read and annotate visible editor segments. The storage permission keeps user-selected check settings on the device.

Contact

Questions and bug reports: CHECKform issue tracker.

Политика конфиденциальности

Обновлено 13 ноября 2026 года. CHECKform читает видимые исходные и переведённые сегменты в редакторе marathonbetops.crowdin.com и показывает возможные замечания в той же вкладке. Проверка выполняется локально. Расширение не изменяет перевод, не передаёт текст сегментов или замечания издателю либо на другой сервер и не использует аналитику или рекламу.

Настройки проверок, изменения глоссария и правила часовых поясов сохраняются локально в хранилище Chrome. Импорт настроек из JSON выполняется только по выбору пользователя; автоматической синхронизации с сайтом CHECKform нет. По вопросам работы расширения используйте раздел Issues.
